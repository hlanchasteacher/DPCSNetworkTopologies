Operator Briefing & Deployment Guidelines

Welcome to the provisioning portal. As a network engineer, you are tasked with deploying hardware for enterprise environments according to A2.2.1 infrastructure standards.

  • Star Topology: Relies on exactly 1 central switch to aggregate traffic. The link allocation ratio is 1:1 (n cables for n nodes).
  • Full Mesh Topology: A decentralized, highly resilient architecture. Requires 0 central switches. Link calculation formula: n(n-1) / 2.
  • Hybrid Topology: Combines architectures to isolate local faults (reducing the blast radius) while maintaining core scalability.

Action Required: Analyze each deployment module below. Calculate the required hardware based on the node count, input the parameters, and validate your configuration.
