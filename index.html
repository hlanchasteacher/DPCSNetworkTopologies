[SYSTEM_INIT] Operator Briefing & Instructions

Welcome to the Architecture Provisioning Terminal. As a network engineer, you are tasked with deploying hardware for enterprise environments according to A2.2.1 curriculum standards.

DIAGNOSTIC PARAMETERS & FORMULAS:

  • Star Topology: Relies on exactly 1 central switch. Cable allocation ratio is 1:1 (n cables for n nodes).
  • Full Mesh Topology: Decentralized point-to-point. Requires 0 central switches. Cable calculation formula: n(n-1) / 2.
  • Hybrid Topology: Combines architectures to isolate local faults (reduce blast radius) while maintaining core resilience.

EXECUTION DIRECTIVE: Analyze each deployment module below. Calculate the required hardware integers based on the node count, input the parameters, and click Execute Build to validate your deployment.
